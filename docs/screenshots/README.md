# Screenshots

Drop UI captures here and reference them from the main [README](../../README.md#screenshots).

Run the app first (`docker compose up --build`, then open http://localhost:5173) and capture at roughly 1280px wide.

| File | What to capture |
|------|-----------------|
| `articles.png` | Home ("Buscar Artigos") with a list of RSS results and the ✨ Generate button |
| `content-detail.png` | Content detail with the PT-BR / EN-US tabs, a post card and the character counter |
| `published.png` | A post marked as published (the ✓ Publicado badge) |
| `demo.gif` | Short end-to-end flow: search → generate → copy |

Keep images optimized (PNG/WebP, under ~500 KB each); GIFs short (a few seconds).
